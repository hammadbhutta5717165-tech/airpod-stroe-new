# AirPods Store — Netlify starter

A responsive static HTML/CSS/JavaScript storefront with product search, category filter, a browser-stored order list, and WhatsApp order-message generation.

## Before publishing
1. Open `script.js`.
2. Replace `STORE_WHATSAPP_NUMBER = "923092702542"` with your WhatsApp number in international digits only. Pakistan example: `923092702542` (replace it with your own number).
3. Review all sample prices, product names, product images, stock claims, delivery details and descriptions.
4. Only describe a product as genuine/original Apple if you have verified authenticity. Clearly label third-party compatible products.
5. The included prices are sample values. Confirm your actual pricing before publishing.

## Test on your phone
Open `index.html` in a code editor preview or upload the folder to Netlify. Internet access is required for the remote Unsplash product photos and Google Fonts. If a photo URL fails, a text fallback appears.

## Deploy to Netlify using Android
1. Extract `airpods-store.zip` on your phone.
2. Visit https://app.netlify.com/drop in Chrome and sign in if requested.
3. Upload/drag the extracted `airpods-store` folder (or upload the folder contents if the screen asks for files). Make sure `index.html`, `style.css`, and `script.js` are at the site's root, not nested inside another folder.
4. Open the generated `*.netlify.app` link to test the site.

## Important limitations
- This is a static website. It does not store orders in a private seller dashboard or process online payments.
- WhatsApp orders are only sent after the customer reviews and presses Send in WhatsApp.
- The order list is saved only in the visitor's browser using localStorage.
- Product images use remote image URLs and may need replacing with your own licensed product photos.
- This is an independent retailer template, not an official Apple website.
